# MVP 路线图与验收标准

## Phase 0：Preset 基础（当前）

交付：角色规则、CDMO 生命周期、数据模型、状态规则、三个核心工作流和模板。

验收：给定一段脱敏项目资料，能明确区分事实、行动项、风险、缺失信息和客户版输出。

## Phase 1：单项目控制塔

范围：项目档案、里程碑、行动项、风险、文件索引、手工更新。

验收：
- 新建项目不遗漏必填字段。
- 任何日期/负责人都能追溯到来源。
- 能查询逾期事项和客户依赖。
- 能按 Green/Amber/Red 解释状态。

## Phase 2：会议到周报

范围：会议纪要解析、行动项登记、风险识别、周报和客户更新稿。

验收：
- 内部版和客户版内容边界清晰。
- 缺少 owner/date 时显示 TBD，不猜测。
- 同一行动项不会因多次会议重复创建。
- 客户邮件中高风险内容自动显示 PM Review Required。

## Phase 3：文件与时间线集成

范围：Word/PDF/Excel 解析、版本比较、主时间线、里程碑冲突和延期模拟。

验收：
- 可识别同一交付物的不同版本。
- 可列出关键路径和受影响里程碑。
- 输入“客户样品延迟 7 天”能给出受影响任务和假设。

## Phase 4：企业连接

范围：Outlook/Teams/SharePoint/OneDrive/Excel/Calendar 的受控连接。

验收：
- 默认读而不写。
- 写入和发送有目标、回执和审计记录。
- 项目数据与外部系统 ID 可回链。
- 连接失败时不伪造已同步状态。

## 明确不纳入第一版

- 自动作出 QA/QC、法务或法规最终结论。
- 自动批准合同变更或客户交付承诺。
- 无审阅直接发送质量事件、延期或商业邮件。
- 将 Harness 作为正式 QMS、EDMS 或 ERP 的替代品。
