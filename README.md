# BioCDMO PM Harness

面向生物药 CDMO 项目经理的项目控制塔 preset 设计初稿。

## 产品定位

BioCDMO PM Harness 不是单纯的写作助手，而是项目事实、承诺、时间线、行动项、风险和客户沟通的统一工作台。

核心链路：

```text
文件 / 邮件 / 会议记录
        ↓
项目事实库
        ↓
Timeline / Action / Risk / Contract
        ↓
周报 / 会议纪要 / 客户邮件 / 管理层报告
```

## MVP

1. 项目档案与状态总览
2. 会议纪要 → 行动项与风险
3. 时间线检查与延期分析
4. 项目周报生成
5. 客户邮件草稿生成

## 当前目录

- `preset/`：角色、规则和数据模型
- `workflows/`：PM 工作流提示与输出规范
- `templates/`：报告、纪要和追踪表模板
- `knowledge/`：CDMO 生命周期与术语知识

## 使用原则

- 区分事实、推断和建议，并保留信息来源。
- 不擅自承诺客户日期、价格、质量结论或合同解释。
- 对延期、偏差、OOS、CAPA、合同及客户承诺标记人工审核。
- 客户版输出客观、专业、可追溯；内部版可直接暴露阻塞和升级建议。
