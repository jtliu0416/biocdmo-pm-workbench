# /meeting-minutes

## 目的
将会议内容转换为可执行、可追踪、可对外发送的项目记录，并把钉钉 AI 听记的原始材料完整归档到项目盘。

## 两条入口

### A. 面板入口（日常浏览零 AI；归档由脚本执行）
右侧栏「📅 会议纪要」标签：

1. **浏览**：列表按 今天 / 本周 / 更早 分组，支持标题搜索；
2. **查看**：点条目标题 → 内置浏览器打开钉钉听记原页；点 `▸` → 面板内看摘要/行动项/关键词/转写；
3. **归档**：`📥 归档` → 把指令发给 Agent，由它运行 `archive-minutes.ps1` 落盘到**当前工作区项目**的 `06-项目会会议纪要`，产出 01~06 编号文件包，并同步 `.pm-cache\archive-index.json`；
4. **打开归档位置**：`📂 已归档` → 原生文件树 + 资源管理器定位。

归档状态：当前项目已归档显示 `✅ 已归档`；仅其他项目归档显示 `📦 已归档于 IPxxx`（此时按钮可归档到当前项目）。

### B. 对话入口（需要 AI 加工时）
在文件树里 **`@` 引用归档产物**（`01-…docx` / `01-…md` / `04-行动项-….csv`），再写指令。推荐引用 `.md`（侧栏可读、文本最完整）。

## 输入
会议日期、参会人、会议记录/转写、项目 ID、会议目标。

## 处理要求
- 区分 Confirmed Decision、Discussion、Open Question。
- 每个行动项尽量提取 owner、owner type、due date、依赖和来源。
- 没有明确负责人或日期时，不要猜测，标记 `TBD`。
- 识别新增风险、问题、变更和客户承诺。
- 生成内部版与客户版；客户版隐藏内部归责和未经确认的推断。
- **项目归属取自当前会话工作区**；内容里没有项目号时先问 PM，不要猜。

## 输出
1. Internal Minutes
2. Client Minutes
3. Decisions
4. Action Register
5. Risks / Issues / Changes
6. Decisions Needed
7. Follow-up Email Draft

## 归档约定（与面板一致）
- 目录：`<项目根>\06-项目会会议纪要\<项目ID>-<yyyy.MM.dd>-<标题>\`
- 编号：`01` 纪要（docx + md）· `02` 录音 · `03` AI摘要 · `04` 行动项 · `05` 逐字稿 · `06` 关键词
- 录音不可得（过期/无痕）时记 warning，不影响其余产物落盘
- 同项目重复归档不覆盖，需显式覆盖

数据缓存：面板只读 `%USERPROFILE%\.pm-workbench\cache\`（面板用 `~` 形式读取）。**同步一次，所有项目工作区同时生效**；切项目不需要重新同步。**禁止再引入宿主路由取数**：历史上宿主 apply 调用时机不可控、热加载会注销路由、每次改动都要重启 DSH。
