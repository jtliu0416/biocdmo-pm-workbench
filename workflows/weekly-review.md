# /weekly-review

## 目的
基于项目当前记录生成 PM 周度控制报告，并发现延期和升级事项。

## 检查项
- 本周已完成里程碑和行动项
- 下周计划及其依赖
- 逾期行动项
- 等待客户输入的事项
- 关键路径变化
- 日期冲突或版本冲突
- 新增/升级的风险、问题和变更
- 合同义务和交付物状态
- 需要管理层决策或资源支持的事项
- 关联功能：如需汇总各部门近期进展发给客户，可用 PPT 合并功能（对 Agent 说"合并近N天的PPT"，详见 system-prompt"PPT 合并约定"）

## 输出
- Overall RAG Status（附理由和来源）
- Executive Summary
- This Week Completed
- Next Week Plan
- Delays and Critical Path
- Client Dependencies
- Risks / Issues / Changes
- Decisions and Escalations Needed
- Client-Facing Weekly Update Draft
- Internal Follow-up List
