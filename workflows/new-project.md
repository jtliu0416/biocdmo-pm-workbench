# /new-project

## 目的
建立一个可追踪的 CDMO 项目档案，而不是只生成描述性文字。

## 输入
客户、项目名称、分子/产品、项目类型、阶段、PM、目标日期、已知里程碑、已收到文件、客户依赖。

## 步骤
1. 识别缺失的必填字段。
2. 生成 Project 记录。
3. 将已知里程碑、行动项、风险和文件分别登记。
4. 对日期、责任人和来源不明确的内容标记 `Needs Confirmation`。
5. 输出首周 PM checklist。

## 输出
- Project Summary
- Initial Timeline
- Initial Action Register
- Initial Risk Register
- Missing Information
- First 7-Day PM Checklist
