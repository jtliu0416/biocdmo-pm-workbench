# PPT 合并功能（merge-ppt.ps1）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一键把 `05-项目进展汇报` 下各部门最近更新的 PPT（每部门最新一份）合并成带统一模板封面/尾页的完整汇报 PPT。

**Architecture:** PowerShell 脚本 `merge-ppt.ps1` 提供 `-Scan`（产出 JSON 候选清单）与 `-Merge`（PowerPoint COM 合并）两个动作；Agent 按 `preset/system-prompt.md` 新增规则编排"扫描→确认→合并"对话流。

**Tech Stack:** PowerShell 5.1+（Windows PowerShell / pwsh 均可）、PowerPoint COM（本机为 WPS 提供的 `PowerPoint.Application` 兼容层）、python-pptx 仅用于验证检查。

## Global Constraints

- 排除 `00-SUM` 目录（它是输出目录）；只扫 `01-*` 至 `12-*` 部门文件夹。
- 每个部门只取修改时间最新的一份 `.pptx`；不认 `.ppt`/`.pdf`。
- 每份源 PPT 只插入第 2 页至倒数第 2 页（去首尾页）；页数 < 3 跳过并警告。
- 合并顺序：部门文件夹编号升序，同部门（不会有多份）忽略。
- 封面=模板第 4 页，替换文本 `IPXXXX`→项目ID、`202X.XX.XX`→汇报日期；尾页=模板第 23 页。
- 输出默认 `05-项目进展汇报\00-SUM\<项目ID>-项目进展汇报-合并-<yyyy.M.d>.pptx`；已存在须先经 Agent 向 PM 确认再覆盖（脚本用 `-Force` 显式允许覆盖）。
- COM 路径必须用纯 UNC（不要 `FileSystem::` 前缀）；清理阶段 Quit 的 RPC 异常必须忽略（try/catch 包裹）；不得用无密码/无参数方式打开可能弹窗的文件。
- 所有输出信息用中文；不回显任何敏感信息。

- [x] **Step 1: 写脚本骨架与 Scan 实现**（param 块、`Resolve-Path.ProviderPath` 取路径、Get-ChildItem 过滤、按部门 Group-Sort 取最新、页数用 python-pptx 只读统计）

```powershell
param(
  [Parameter(Mandatory=$true)][string]$Project,
  [Parameter(Mandatory=$true)][ValidateSet('Scan','Merge')][string]$Action,
  [int]$Days = 3,
  [string]$ListPath,
  [string]$OutputPath,
  [string]$ReportDate,
  [switch]$Force
)
$ErrorActionPreference = 'Stop'
$root = '\\C-FILESERVER\06-项目管理部\01-Project-Ongoing\' + $Project + '\05-项目进展汇报'
if (-not (Test-Path -LiteralPath $root)) { throw "目录不存在：$root" }
[Console]::OutputEncoding = [Text.UTF8Encoding]::new($false)
$deptDirs = Get-ChildItem -LiteralPath $root -Directory |
  Where-Object { $_.Name -match '^\d{2}-' -and $null -ne ($_.Name -replace '^(\d{2}).*$','$1' -as [int]) } |
  Sort-Object { [int]($_.Name -replace '^(\d{2}).*$','$1') }
$cutoff = (Get-Date).AddDays(-$Days)
$candidates = @(); $dropped = @()
foreach ($d in $deptDirs) {
  $files = Get-ChildItem -LiteralPath $d.FullName -Filter '*.pptx' -File |
    Where-Object { $_.LastWriteTime -ge $cutoff } | Sort-Object LastWriteTime -Descending
  if (-not $files) { continue }
  $latest = $files[0]
  # 页数统计（只读，用 python-pptx；失败则记 slides=-1 并入 warnings）
  ...
  $candidates += [pscustomobject]@{ dept=$d.Name; path=$latest.FullName; lastWrite=$latest.LastWriteTime.ToString('yyyy-MM-dd HH:mm:ss'); slides=$slides }
  foreach ($old in ($files | Select-Object -Skip 1)) {
    $dropped += [pscustomobject]@{ dept=$d.Name; path=$old.FullName; lastWrite=$old.LastWriteTime.ToString('yyyy-MM-dd HH:mm:ss') }
  }
}
[pscustomobject]@{ project=$Project; days=$Days; candidates=$candidates; dropped=$dropped; warnings=$script:warnings } |
  ConvertTo-Json -Depth 4
```
